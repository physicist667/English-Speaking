# TalkPal — разговорная практика английского с ИИ-собеседником

Веб-приложение для тренировки устной английской речи: говорите голосом, ИИ-собеседник отвечает живым человеческим голосом, а после диалога вы получаете подробный разбор вашей речи.

## Возможности

- **Голосовой диалог с ИИ** — говорите в микрофон, собеседник отвечает голосом (Web Speech API для распознавания, нейронный TTS для озвучки)
- **Естественные нейроголоса** — Microsoft Edge Neural (Ava, Andrew, Emma, Brian, Sonia, Ryan): мужские/женские, американский и британский акценты. Автоматический резерв: Google TTS → встроенный TTS
- **Реальные субтитры** — речь собеседника дублируется текстом с подсветкой произносимой фразы
- **4 уровня сложности речи** — от «мягкого старта» до «хардкора» (темп, идиомы, сленг — характер речи меняется, а не словарный запас)
- **3 уровня словарного запаса** — простой (A1–A2), средний (B1–B2), богатый (C1+): собеседник подбирает слова под ваш уровень
- **Короткие живые реплики** — собеседник говорит 1–2 короткими фразами, как в реальном голосовом чате
- **Собеседник сам предлагает темы** — либо задайте свою тему в настройках
- **Инжекция слов** — загрузите список слов (файлом .txt/.csv или вставкой), и ИИ естественно вплетёт их в диалог
- **Разбор диалога** — уровень CEFR, ошибки «было → стало» с объяснениями на русском, удачные фразы, использованные целевые слова, рекомендации. Артефакты распознавания речи (STT) не засчитываются как ваши ошибки
- **Архив диалогов** — расшифровки и разборы хранятся прямо в браузере + экспорт/импорт резервной копии
- **Без базы данных и почти без настройки** — диалоги и слова живут в localStorage вашего браузера; для ИИ достаточно один раз вставить бесплатный ключ в настройках приложения

## Требования

- Node.js 18+ (или Bun 1.1+)
- Доступ в интернет (для ИИ и TTS)

## Запуск локально

```bash
# 1. Установить зависимости
bun install          # или: npm install

# 2. Запустить
bun run dev          # или: npm run dev
```

Приложение откроется на http://localhost:3000

> Настройка ИИ: откройте настройки (иконка шестерёнки) → «Подключение ИИ» → вставьте бесплатный ключ. В песочнице-превью ключ не нужен — там работает встроенный ИИ.

## Как пользоваться

1. **Подключение ИИ (один раз)**: настройки → «Подключение ИИ» → выберите провайдера → получите бесплатный ключ по ссылке → вставьте → «Проверить»
2. **Разговор**: нажмите «Начать разговор» — собеседник поздоровается и предложит темы. Отвечайте голосом (микрофон) или текстом
3. **Слова**: загрузите свои списки слов и включите их — ИИ будет использовать их в речи
4. **Разбор**: завершите диалог и получите ошибки, удачные фразы и рекомендации
5. **Архив**: все прошлые диалоги с расшифровками и разборами. Кнопки «Экспорт»/«Импорт» — резервная копия всех данных

## Подключение ИИ

Приложение работает с любым OpenAI-совместимым API. Выберите **один** вариант:

| Провайдер | Где взять ключ | Модель по умолчанию |
|---|---|---|
| **Google Gemini** (рекомендуется) | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — щедрый бесплатный тариф | `gemini-2.5-flash` |
| OpenRouter | [openrouter.ai/keys](https://openrouter.ai/keys) — есть модели `:free` | `meta-llama/llama-3.3-70b-instruct:free` |
| Groq | [console.groq.com](https://console.groq.com) — быстрый бесплатный тариф | `llama-3.3-70b-versatile` |
| OpenAI-совместимый | любой сервис | `gpt-4o-mini` |

Ключ можно вставить **в настройках приложения** (хранится в вашем браузере, нулевая настройка хостинга) **или** задать на сервере переменной окружения `GEMINI_API_KEY` / `OPENROUTER_API_KEY` / `GROQ_API_KEY` / `OPENAI_API_KEY` (env имеет приоритет). Дополнительно: `AI_MODEL` — своя модель, `OPENAI_BASE_URL` — свой адрес API.

> ⚠️ Ключ в настройках уходит в запросах к вашему же серверу приложения — не публикуйте ссылку на приложение открыто.

## Деплой на Vercel

1. Залейте код на GitHub → в Vercel: **Add New → Project** → Import
2. Deploy — больше настраивать **ничего не нужно** (базы данных нет, сборка обычная)
3. Откройте сайт → настройки → «Подключение ИИ» → вставьте бесплатный ключ (Gemini — минута) → «Проверить» → готово

Альтернатива через env (необязательно): Settings → Environment Variables → `GEMINI_API_KEY` → Redeploy — тогда ключ не нужно вставлять в браузере.

## Структура проекта

```
src/
  app/
    api/
      chat/            — реплика ИИ-собеседнику (stateless: история и слова с клиента)
      analyze/         — разбор диалога LLM (stateless, JSON-протокол)
      ai-check/        — проверка ключа ИИ из настроек приложения
      tts/             — озвучка: Edge Neural → Google TTS → SDK (fallback-цепочка)
    page.tsx           — вкладки: Разговор / Слова / Архив
  components/practice/ — chat-view, settings-panel, words-view, archive-view, analysis-view
  hooks/               — use-speech-recognition (STT), use-tts-player (аудио + субтитры)
  lib/
    ai.ts              — промпты, персонажи, клиенты LLM (env-ключ → ключ приложения → SDK-песочница)
    local-store.ts     — хранение диалогов/слов/разборов в localStorage + экспорт/импорт
    edge-tts.ts        — собственный WS-клиент Microsoft Edge Read Aloud TTS
    practice-config.ts — уровни сложности, голоса, скорость
    parse-words.ts     — парсер файлов со словами
    types.ts           — общие типы
```

## Голоса (TTS)

1. **Microsoft Edge Read Aloud** (основной) — нейроголоса нового поколения: `Ava`, `Andrew`, `Emma`, `Brian` (США), `Sonia`, `Ryan` (Британия)
2. **Google Translate TTS** (резерв)
3. **Встроенный SDK TTS** (последний резерв)

Темп речи регулируется на клиенте (`playbackRate` с сохранением высоты голоса), поэтому голос никогда не искажается.

## Хранение данных

Диалоги, списки слов и разборы хранятся в **localStorage браузера** — на устройстве, где вы практикуетесь. Никакой серверной базы нет: это и делает деплой «нулевым». Чтобы не потерять историю при очистке данных браузера или для переноса на другое устройство — используйте «Экспорт»/«Импорт» на вкладке «Архив».
